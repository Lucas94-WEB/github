## Ordem recomendada

1. Ajustar o perfil do LinkedIn (arquivo 03, Parte 1) — ela vai olhar o perfil em seguida.
2. Montar o currículo em PDF (arquivo 02).
3. Enviar a nota de conexão e a mensagem (arquivo 01) — a vaga é recente, responda rápido.
4. Estudar o roteiro técnico (arquivo 03, Parte 2) enquanto espera o retorno.

> Tudo que está entre `[colchetes]` precisa ser preenchido com seus dados reais.
> Não preencha com experiência que você não tem: a entrevista técnica expõe isso.
