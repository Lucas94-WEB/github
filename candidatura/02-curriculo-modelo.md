## Como escrever cada bullet

A fórmula que funciona: **verbo de ação + o que + com qual tecnologia + resultado medido.**

| Fraco | Forte |
|---|---|
| "Responsável pelo backend do sistema" | "Desenvolvi 14 endpoints REST em ASP.NET Core que sustentam o checkout, com 99,9% de disponibilidade" |
| "Trabalhei com Angular" | "Reconstruí o painel administrativo em Angular 17 com lazy loading, reduzindo o carregamento inicial de 4,1s para 1,3s" |
| "Melhorei a performance do banco" | "Reescrevi 8 queries críticas e criei índices no SQL Server, cortando 70% do tempo do relatório mensal" |

Não tem número exato? Estime com honestidade e diga que é aproximado — isso é aceitável.
O que não vale é inventar projeto, empresa ou período.

## Erros que derrubam currículo de dev sênior

- Listar 40 tecnologias, inclusive as que você viu uma vez. Liste o que você defende numa entrevista.
- Currículo de 4 páginas com descrição de cargo em vez de entrega.
- Nenhuma métrica em lugar nenhum.
- Mandar em `.docx` ou com nome `curriculo-final-v3-ATUALIZADO.pdf`.
- Esconder o GitHub quando ele tem código bom — e expor quando ele só tem repositório vazio.
